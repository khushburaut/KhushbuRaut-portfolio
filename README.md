# 👩‍💻 Khushbu Raut — Personal Portfolio

A modern, responsive personal portfolio website built to showcase my **skills, projects, experience, education, certifications, and achievements** as a B.Tech Computer Science & Engineering student and aspiring **Data Analyst & Web Developer**.

The portfolio features a clean editorial-inspired design with responsive layouts, bold typography, interactive project sections, smooth navigation, and a professional presentation of technical and academic work.

## 📌 About the Project

This portfolio website was developed to create a professional online presence and provide a centralized place to showcase my:

- Technical skills
- Web development projects
- Data analytics projects
- Internship experience
- Academic background
- Certifications
- Coding profiles
- Resume
- Contact information

The website is built using a component-based React architecture, making the project easy to maintain and update.

---

## ✨ Features

- 🎨 Modern and clean editorial-inspired UI
- 📱 Fully responsive design
- 🧭 Smooth section-based navigation
- 👩‍💻 Professional profile and introduction
- 🛠️ Categorized technical skills
- 💼 Internship and experience section
- 🎓 Education and academic information
- 🚀 Project showcase with category filtering
- 🏆 Certifications and achievements
- 📊 Coding profile information
- 📄 Resume access
- 🔗 GitHub, LinkedIn and LeetCode integration
- 📩 Contact section
- ⚡ Fast development and production build using Vite
- 🌐 Deployed and hosted on Vercel
